# RealPilot / 驭真科技 官网

这是一个可以直接放进 GitHub Pages 的纯静态官网。页面没有构建步骤，也没有后端依赖。

## 发布到组织官网

1. 在 `real-pilot` 组织下创建公开仓库：`real-pilot.github.io`。
2. 把本目录下的全部文件上传到仓库根目录。
3. 仓库内的 `.github/workflows/pages.yml` 会自动部署到 GitHub Pages。
4. 等待 Actions 完成，访问 `https://real-pilot.github.io`。

图片素材来自用户提供的 BP 页面；主视觉与动效为官网呈现层设计。对外正式发布前，建议确认素材授权并补充团队联系方式。
